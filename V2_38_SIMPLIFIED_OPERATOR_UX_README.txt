GoldScope v2.38 - Simplified Operator UX

Builds on v2.37.

Purpose:
Reduce UX confusion by making the main navigation operator-focused.

Visible top navigation:
- Home
- Chart
- Events
- Scenario
- AI Analysis
- Health
- Export
- Settings

Hidden from main daily navigation:
- News Intelligence
- FRED Macro Drivers
- Macro Calendar
- Event Results
- Event Replay
- Auto Tracker
- Post-Event Tracker
- Bias Engine

These advanced pages still exist internally and can be reached from action buttons or future debug links, but they are no longer part of the normal daily operator flow.

Recommended workflow:
1. Normal day:
   Home → Run Smart Analysis
2. Before a major event:
   Events
3. After a completed event:
   Home → Run post-event update
4. Deeper explanation:
   AI Analysis
5. Debug/source checking:
   Health

No credential/FRED key files are included or overwritten.
