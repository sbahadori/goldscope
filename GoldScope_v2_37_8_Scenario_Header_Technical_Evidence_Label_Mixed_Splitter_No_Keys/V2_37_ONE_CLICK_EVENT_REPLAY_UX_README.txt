GoldScope v2.37 - One-Click Event Replay UX

Builds on v2.36.5.

Purpose:
Simplify Event Replay UX.

Changes:
- Removes/masks confusing manual replay workflow from the visible UI.
- No Capture Pre-Event Anchor.
- No Save Post-Event Replay.
- Event Replay becomes a single-action page:
  - Before event: no action needed; go to Event Risk.
  - After event: click Replay completed events.
  - Then go to AI Engine and run analysis.

Why:
The previous workflow required moving between AI Engine and Event Replay multiple times and was confusing. Replay reconstruction should be post-event and one-click.

No credential/FRED key files are included or overwritten.
